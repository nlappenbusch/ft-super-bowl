📋 Anleitung

  1. Dev-Server starten: npm run dev
  2. Diese Seite öffnen: test-wordpress-preview.html im Browser (Datei direkt öffnen)
  3. Komponenten testen: Alle Shortcodes sollten automatisch laden
  4. In WordPress verwenden: Plugin installieren und Shortcodes kopieren

Troubleshooting:

  • ❌ CORS Fehler? → Normal bei File-Protokoll, funktioniert in WordPress
  • ❌ Nicht geladen? → Dev-Server läuft auf Port 3000?
  • ✅ Funktioniert? → Bereit für WordPress-Integration!
